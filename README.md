# Hotel Arcade

A small collection of browser games. No installs, no outside libraries. Just open `index.html`, or host it with GitHub Pages.

Games: Pulse Runner, Gravity Flip, Star Hopper, Checkers, Reversi, Mancala, Dots & Boxes, Tic-Tac-Toe, Four in a Row, Snake, Brick Smash, Memory Match, Mine Sweep, Word Balloon, Slide Puzzle, Color Echo.
